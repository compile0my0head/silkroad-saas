# SilkRoad — AI Social Media Automation SaaS

## Overview
SilkRoad is a SaaS platform that helps small online stores automate:
- Customer conversations (AI chatbot)
- Order creation from chat
- Social media campaign publishing

## Tech Stack
- Backend: .NET 8 (Clean Architecture)
- Frontend: Angular
- Database: SQL Server
- Automation: n8n

## Architecture
The system follows Clean Architecture:
- Domain: core business logic
- Application: use cases & services
- Infrastructure: database & integrations
- Presentation: API layer

## Key Features
- Multi-tenant store system
- AI chatbot order extraction
- Campaign scheduling & publishing
- Facebook integration

## Project Structure
/backend → API & business logic  
/frontend → UI (Angular)  
/docs → architecture & system design
